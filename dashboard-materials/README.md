# 数据大屏组件素材库

本目录用于后续重制工业互联网平台首页。组件源码与当前 `dist_mes` 运行包隔离，便于查看示例、挑选视觉元素，并在取得 Vue 源码工程后按需集成。

## 已拉取组件

| 目录 | 版本/提交 | 用途 | 使用建议 |
| --- | --- | --- | --- |
| `components/DataV` | 2.10.0 / `417ade7` | SVG 科技边框、装饰线、滚动表格、数字翻牌 | 优先挑选边框、装饰和滚动列表，不使用它替代现有 ECharts |

每个上游项目均保留自己的 Git 元数据和许可证，后续可追溯来源。

## 推荐组合

```text
原生 video（UE5 产线视频）
  + CSS 半透明玻璃面板
  + DataV 边框/装饰/滚动表格
  + 现有 ECharts 图表
  + CountUp 数字动画
  + v-scale-screen 1920×1080 适配
```

## 当前首页状态

首页已调整为全屏视频构图：UE5 视频作为整个内容区的底层画面，标题、指标、左右生产数据栏、底部趋势与工单区以半透明 HUD 形式覆盖在视频上方，中央主视区保持通透。视频画面内不再叠加设备标签、状态角标或中心准星。

首页进入专属沉浸模式时会隐藏顶部白色导航栏和标签栏，使数据大屏占满浏览器高度；离开首页进入其他业务模块时，原导航会自动恢复。左侧业务菜单仍然保留。

- Vue 2 首页模块：`dist_mes/static/js/chunk-7ea63fd3.video145620.js`
- 首页样式：`dist_mes/static/css/industrial-dashboard-modern.css`
- 大屏样式：`dist_mes/static/css/industrial-dashboard.css`
- 两个文件对应的 Gzip 版本已同步生成。
- 入口 chunk 映射已改用独立的 `video20260901` 资源名，避免旧布局缓存。
- UE5 产线视频已通过 `dist_mes/static/video/production-line-145620.mp4` 接入，对应根目录 `video/VID_20260901_145620.mp4`。该文件使用 NTFS 硬链接，不重复占用空间。
- 视频采用静音自动播放、循环、铺满裁切；未加载成功时保留工业线框背景。
- 大屏中的装饰性英文、英文设备状态和英文模块编号均已移除或中文化；计量单位与业务编号保留。
- 数据模块按 MES 业务链重构为接单、待排产、计划产量、准交率、订单执行、产线负荷、今日排产、交付与齐套风险、计划/实际产出和工单执行。
- 左上角识别模块已改为“啤酒智能罐装 / 柔性排产中心”，并使用代码绘制的罐体标识。
- 大屏视觉升级为现代玻璃拟态企业看板：圆角弱边框、分层阴影、状态胶囊、柔和渐变与低干扰图表，移除传统四角描边式大屏装饰。
- 当前数值仍为布局演示数据，下一阶段再连接 MES/MQTT 实时接口。

替换前的文件保存在 `dist_mes` 对应目录，文件名包含 `before-home-reset-20260831`、`before-home-cache-bust-20260831` 或 `before-industrial-dashboard-20260831`，需要时可以恢复。

## 后续集成注意

- 当前目录是可运行部署包，并不包含完整 Vue 工程，不能在 `dist_mes` 中执行 `npm install`。
- 正式实现优先获取原 Vue 2 源码；如果暂时无法取得，再建立独立的大屏页面并由 Nginx 托管。
- UE5 视频使用浏览器原生 `<video muted autoplay loop playsinline>`，不额外引入播放器。
- 大屏按 1920×1080 设计，视频中心区域预留给产线，数据栏放置在左右两侧和底部。
